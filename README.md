# SIGNAL Replica

基于 HTML、CSS、JavaScript 和 Canvas 实现的交互式数字演出网页，尝试复刻《Phigros》主线第九章曲目 **Desultory Signals** 开场动画中的“难度提升”部分。

项目由 [Lylighte](https://github.com/Lylighte) 创建，支持自定义内容、数字滚轮动画、视觉效果调整、关键帧编辑、音频同步，以及 MP4、PNG 帧序列和 GIF 导出。

所有动画渲染与媒体编码均在浏览器本地完成，无需视频处理后端或本地 FFmpeg。

**[在线体验](https://lylighte.github.io/signal-replica/)** · **[项目仓库](https://github.com/Lylighte/signal-replica)** · **[问题反馈](https://github.com/Lylighte/signal-replica/issues)** · **[开源许可证](LICENSE)**

## 功能特性

### 内容与布局

- 支持 1–16 个自定义选项，数字支持 1–4 位并保留前导零。
- 支持新增、删除、排序选项及导入旧版配置。
- 支持单项聚焦、轮播、分页和多选项同屏显示。
- 提供自动、2×2、3×3、4×4 网格布局。
- 支持自定义布局间距、页码、选项顺序及画面适配方式。
- 支持 16:9、4:3、1:1、9:16 四种画幅。
- 提供居中裁剪、自适应缩放和智能重排模式。
- 针对桌面端、移动端及有限高度视口进行布局适配。

### 动画与时间轴

- 数字滚轮、文字选择、光晕、扫描线、曲面与故障动画。
- 可分别调整入场、选择、滚动、稳定、故障和退场阶段时长。
- 可视化关键帧轨道，支持新增、选择、复制、删除及拖动。
- 支持为数字、标签、选项和图层属性设置关键帧。
- 支持 Linear、Ease In、Ease Out、Ease In Out 插值。
- 可调节图层位置、缩放、旋转、透明度与故障强度。
- 支持播放头精确定位、时间轴缩放及任意时间点预览。
- 预览与离线导出采用确定性时间映射，不依赖实时屏幕录制。

### 外观与视觉效果

- 自定义数字、文字、背景、光晕、扫描线和故障颜色。
- 支持 HEX、RGB、RGBA 与 `linear-gradient(...)`。
- 支持 RGB 色差、条带偏移、震动和五阶段向上抖动效果。
- 支持按时间和音乐节拍触发视觉变化。
- 内置原版、纯白、粉色、紫色、青色、赛博霓虹及 RGB 主题。
- 支持自定义主题的本地保存、导入、导出和删除。

### 字体与图层

- 支持 TTF、OTF、WOFF、WOFF2 字体。
- 可调节字号、字重、字距、描边和阴影。
- 支持文字、PNG、JPEG、WebP 和 SVG 图片图层。
- 支持位置、大小、旋转、透明度、层级、混合模式、遮罩及发光。
- 图层可使用关键帧及入退场动画。
- 预览和导出使用相同的图层渲染逻辑。

### 音频与节拍同步

- 支持原版音轨、自定义音轨或无音轨。
- 支持浏览器可解码的 MP3、WAV、FLAC、M4A/AAC、Ogg/Opus 和 WebM 等音频格式。
- 支持 0–400% 音量调整、静音、裁剪、循环、淡入和淡出。
- 支持自定义音轨在项目时间轴上的起止位置。
- 支持手动设置 BPM、节拍偏移、细分和效果强度。
- 可通过节拍触发闪屏、数字跳动、RGB 分离与震动。
- 可使用 Web Audio 在本地估算导入音乐的节拍。
- MP4 导出支持 AAC 音轨，并对编码延迟与时间轴进行处理。

实际音频格式支持范围取决于浏览器及操作系统。

### 项目、模板与批量处理

- 使用 `signal-studio` v2 JSON 保存项目。
- 兼容旧版项目文件、设置对象及选项数组。
- 内置原版 SIGNAL、音游成绩、系统启动、身份认证及数字倒计时模板。
- 支持本地模板的保存、应用、复制、删除、导入和导出。
- 可通过 URL Fragment 分享经过清理的项目配置，无需后端服务。
- 分享配置不会包含音频、字体和图片二进制资源。
- 支持批量任务队列、文件名模板、ZIP 打包、任务取消及失败重试。
- 高负载编码任务采用串行执行，避免多个编码器同时占用大量内存。

## 视频与动画导出

项目提供三种导出格式：

| 格式 | 说明 |
| --- | --- |
| MP4 | H.264 视频，可选 AAC 音频 |
| PNG ZIP | PNG 帧序列及配置清单 |
| GIF | 彩色动画，支持多档压缩 |

三种格式均采用项目渲染逻辑，支持进度反馈、取消操作、错误处理与资源清理。

### MP4 导出

**支持的分辨率：**

| 档位 | 16:9 | 4:3 | 1:1 | 9:16 |
| --- | --- | --- | --- | --- |
| 1080p | 1920×1080 | 1440×1080 | 1080×1080 | 1080×1920 |
| 2K / QHD | 2560×1440 | 1920×1440 | 1440×1440 | 1440×2560 |
| 4K UHD | 3840×2160 | 2880×2160 | 2160×2160 | 2160×3840 |

**编码参数：**

- 帧率：30、60、90、120、144、165 FPS。
- 视频编码：H.264。
- 音频编码：AAC（可选）。
- 视频码率：画质预设或自定义 1–1000 Mbps。
- 支持自定义导出起止时间。
- 支持编码能力检测及 H.264 Level 检查。
- 支持输出容器有效性检查。

渲染器直接按目标分辨率创建 Canvas，不通过放大 1080p 画面生成 2K 或 4K 视频。

应用会在导出前检查浏览器编码能力。实际可用分辨率、帧率和码率组合以当前设备的检测结果为准。

### PNG 帧序列导出

- 支持四种画幅及相同的分辨率档位。
- 支持 1–165 FPS。
- 单次最多导出 5000 帧。
- 支持自定义时间范围。
- 输出 ZIP 文件，包含 PNG 图片及 `manifest.json`。
- 包含所选时间范围结束时刻的画面。

### GIF 导出

- 最高支持 720p。
- 支持四种画幅。
- 提供标准、压缩、高压缩和极限四档。
- 默认配置为 240p / 6 FPS / 32 色。
- 极限档默认配置为 90p / 4 FPS / 16 色。
- 支持跨帧自适应调色板、重复帧合并和变化区域裁切。

GIF 不包含音轨。

## 使用方式

1. 打开在线页面，在右侧编辑区域设置选项、数字及画面参数。
2. 使用播放、暂停或时间轴定位功能预览动画。
3. 如需更多编辑功能，可点击「高级功能」，调整布局、关键帧、音频、图层、字体和主题。
4. 点击「导出…」，选择 MP4、PNG ZIP 或 GIF。
5. 设置画幅、分辨率、帧率、时间范围及相应参数。
6. 通过兼容性检查后开始生成，完成后由浏览器下载文件。

导出过程在本地浏览器执行，性能及资源占用取决于设备配置。

## 本地运行

### 环境要求

- Node.js 20 或更新版本。
- 支持现代 JavaScript 的浏览器。
- MP4 导出需要浏览器具备相应 WebCodecs 编码能力。

### 安装与启动

克隆仓库：

```bash
git clone https://github.com/Lylighte/signal-replica.git
cd signal-replica
```

安装依赖：

```bash
npm install
```

运行测试：

```bash
npm test
```

启动本地服务：

```bash
npm start
```

访问：

http://127.0.0.1:4173/

`localhost` 和本地回环地址通常属于浏览器认可的可信环境，可以使用 WebCodecs 等相关 API。

### 更新浏览器依赖

项目已包含发布使用的 `dist/vendor/` 文件，日常启动与部署无需重新构建。

更新 Mediabunny 等依赖后，执行：

```bash
npm run build:vendor
```

## 静态部署

项目不依赖专用后端、数据库或付费视频编码 API，可部署到常见静态托管平台。

### GitHub Pages

仓库已包含 GitHub Actions 部署工作流。

在 **Settings → Pages → Build and deployment** 中，将部署来源设置为 **GitHub Actions**。

工作流会直接发布 `dist/` 目录。

默认项目地址：

https://lylighte.github.io/signal-replica/

### Cloudflare Pages

使用以下配置：

| 选项 | 配置 |
| --- | --- |
| 构建命令 | 留空 |
| 输出目录 | `dist` |
| 后端服务 | 不需要 |

### Astro

如需嵌入 Astro 项目，可将 `dist/` 目录中的全部文件复制到：

```text
public/signal-replica/
```

随后通过 `/signal-replica/` 访问。

项目使用相对资源路径，以便在子目录中加载模块、字体、音频和依赖文件。

## 技术实现

| 功能 | 技术 |
| --- | --- |
| 页面与交互 | HTML、CSS、JavaScript |
| 画面渲染 | Canvas |
| 动画时间轴 | 确定性时间映射与关键帧 |
| 视频编码 | WebCodecs / H.264 |
| MP4 封装 | Mediabunny 1.62.0 |
| AAC 编码 | @mediabunny/aac-encoder 1.62.0 |
| 音频处理 | Web Audio |
| GIF 编码 | 调色板、LZW、帧差编码 |
| 项目保存 | JSON |
| 静态部署 | GitHub Pages、Cloudflare Pages 等 |

预览、MP4、PNG ZIP 和 GIF 共享核心渲染逻辑，包括布局、时间映射、关键帧、音频节拍效果、图层和视觉故障处理。

导出采用逐帧渲染，不需要对网页进行实时屏幕录制。

## 浏览器兼容性与限制

### 浏览器支持

MP4 导出需要：

- HTTPS 或可信本地环境。
- WebCodecs H.264 编码能力。
- Web Worker。
- WebAssembly。
- Web Audio。
- Canvas。

建议使用较新版本的 Chrome、Edge 或 Safari。

Firefox、Linux、移动设备及企业管理环境可能存在不同程度的编码支持限制。

PNG ZIP 和 GIF 不依赖 WebCodecs H.264 编码，但仍受到 Canvas、字体及图片解码能力的限制。

### 编码与资源限制

- MP4 / ZIP 单次缓冲预算约为 1 GiB。
- MP4 单次最多 120000 帧。
- PNG ZIP 单次最多 5000 帧。
- PNG 和批量打包所使用的 ZIP32 不支持超过 4 GiB 的 ZIP 文件。
- 自定义音频文件上限为 128 MiB。
- 自定义字体文件上限为 64 MiB。
- 自定义图片文件上限为 64 MiB。
- 解码后的音频数据上限为 512 MiB。
- 图片单边尺寸不得超过 16384 像素，总像素不超过约 64 MP。

4K、高帧率、复杂图层、16 项同屏或较长时间的动画可能显著增加内存、显存和编码负载。

应用会进行编码兼容性及资源预算检查，在无法满足要求时提示错误，而不是静默降低所选规格。

### 本地文件与项目配置

- 自定义音乐、字体和图片仅在用户浏览器本地处理，不会上传到项目服务器。
- 项目 JSON、模板及分享链接不包含这些资源的原始二进制数据。
- 重新载入项目或跨设备使用时，可能需要重新选择本地资源。
- 自动节拍检测属于启发式估算，复杂音乐建议手动校准 BPM 和偏移。
- 取消导出后，浏览器回收已提交的编码任务资源可能仍需要一定时间。

## 自动化测试

运行：

```bash
npm test
```

测试内容包括：

- 项目配置迁移与 JSON 安全。
- 16 项布局及四种画幅。
- 关键帧与时间轴插值。
- 字体、主题、图层和模板。
- Beat Sync 及音频裁剪、循环与淡入淡出。
- 批量任务、取消及 ZIP 打包。
- MP4 帧率、分辨率与 H.264 Level。
- AAC 音轨、MP4 容器时长与资源清理。
- GIF LZW、调色板、重复帧及变化区域裁切。
- RGB 色差、抖动包络与部分安全回归场景。

Node.js 测试不能替代真实浏览器的编码器验证。

建议在目标浏览器中检查高分辨率、高帧率、自定义音轨、图层、字体、非零起始时间及中途取消等场景。
