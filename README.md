# SIGNAL 数字演出

本地可交互网页，使用 Saira 字体复刻 `ref2.mp4` 中的选项入场、标签选择、数字出现、停留、加速滚动、方向拖影和故障收尾。参考中的水印和 iOS 悬浮球不参与绘制。出场故障时点按完整参考的 30 fps 帧号校准，其余运动仍为程序重建，尚未逐帧拟合到原片。

当前动作顺序：选中项按下后短暂消失再显示，然后水平移到中央；其他项拉开字符间距并向左右移出；标签默认采用 0.75 秒的 Sigmoid 展开，陡度为 13（网页也可选择二次方或次方），在展开期间通过两组撕裂反色效果显现已在滚动的数字卷轴。入场字号固定，无缩放动画；第二组效果结束时，目标数字已到中央附近，只剩 14 像素的缓动就位。加速滚动开始后，选项文字缓缓向两侧离场；数字列整体向右推进，新的高位从左侧逐列渐入，每个单画面最终为 5 列。时点集中在 `config.js` 的 `MOTION` 中。

完整参考校准：补齐约 2.13 秒的前导时间后，时间轴总长约 17.51 秒。开头约 0.55 秒为选项收拢和模糊消退；约 2.03–2.43 秒只有选中项短暂压暗、消失再显示；约 2.93 秒开始依次展开并移出未选中项，选中项水平居中。约 4.57–4.83 秒为第一组出场故障，4.97–5.27 秒为第二组；灰色洗屏帧、反色帧和撕裂帧分别处理。数字在第一组反色帧中开始可见，仍处于展开阶段；从 5.27 秒起只保留末尾缓动；接近对齐时约束右侧列不反超左侧列；相邻列的就位错开可调，当前默认 0 秒。约 8.03 秒开始加速，10.93 秒开始追加高位并向右推移。

两次闪烁指画面撕裂、反色，数字始终采用同一组连续卷轴，不做数值切换或透明度闪断。每列均按 0、1、2…9、0 循环排列；出场从各列前一个数字滚至目标，如 IN 17 从 06 滚至 17，十位入场先慢后接近对齐，个位不会反超。相邻行间距按字形和光晕的完整边界计算，静止时上下行都在画面外，滚动时才进入画面。前导零保留。加速阶段从个位向高位错开，十位初始速度为个位的四分之一，更高位更慢；随后各位逐渐接近相同高速，各自滚动位置保持连续。

数字使用两层柔和光晕，字形和光晕统一受整个画布的椭圆晕影影响：中央最亮，向四周逐渐变暗。亮度场以乘色作用于内容，空白区域保持黑色，文字移动时会经过不同亮度区域；出场及收尾故障的反相闪光为独立效果。微弱扫描线在最终合成后作用于数字、标签及光晕，暗部变化随原亮度减弱，纯黑区域不受影响；滚动拖影不会抹掉此纹理。

## 打开

在此目录运行 `node serve.mjs`，然后打开 http://127.0.0.1:4173/ 。网页文件位于 `dist/`，无第三方运行依赖；已安装 npm 时也可运行 `npm start`。

## 当前功能

- 自定义 1–8 个选项；每个名称为 1–12 个字符，数字为 1–4 位非负整数。
- 保留前导零，兼容全角数字。无效输入会显示原因，画面保留上一次有效内容。
- 同屏/单画面布局，单画面可选择任意选项。
- 播放、暂停、重播、时间拖动、参考静帧和全屏。
- 导出 PNG 视频帧 ZIP：设置起止时间、1–120 FPS 和 16:9/4:3 画幅；包含逐帧 PNG 和 `manifest.json`，单次最多 5000 帧。
- Space 播放/暂停；左右方向键移动 1/30 秒（编辑输入时不拦截按键）。
- 默认静音，可开启 `audio.wav` 原始音轨（44.1 kHz、16-bit、双声道，17.5078458 秒）。直接复制使用，不添加静音、不转码；开启声音后，页面以该音轨时间作为播放时钟。
- 字体和音频都在本地加载。自定义内容只保存在当前页面内存中。

## 网页调节画面参数

“编辑内容 → 画面参数”按数字外观、间距、选项文字、入场按下、选择展开、数字就位、加速右推、画面亮度、扫描线曲面、噪声故障分组。滑块用于常用调节区间，输入框允许超出滑块上下限并显示提示。默认值统一来自 `dist/default-settings.js`，完整对应用户提供的 `signal-settings.json`，包括选项、画面参数和预览：单画面、AT 18、16:9。当前默认开启曲面、字号 400、数字光晕 45、初始横向间距 260、最终横向间距 170、Sigmoid 展开陡度 13。修改后可恢复默认参数。Sigmoid 仅作用于选项展开。

参数定义、范围、默认值和编辑界面共用 `dist/design.js`，渲染器读取同一份参数。无效值会显示原因并保留之前的有效画面；批量修改先完整校验再提交。字号和光晕增大时，纵向间距会自动保证静止相邻行完全位于画面外。最终横向间距直接采用输入值，允许数字列超出左右边界，超出部分由画面窗口裁切，不再按列数自动压缩间距。

本次默认配置使用新的存储版本，旧版本的本机参数不会覆盖新默认值；旧数据仍保留。后续画面参数存入本机浏览器的 `signal-design-v2`，刷新后恢复；该存储不包含选项文本和数字。`window.ReplicaApp.setDesign({numberSize:360,numberGlowStrength:.6})` 和对应 WebMCP 工具与网页控件更新同一份状态。

## 正式发布改为“选项预设”

修改 `dist/config.js` 中的配置：

```js
optionSource: { mode: 'preset', presetId: 'four-difficulties' }
```

在同一文件的 `PRESETS` 中维护预设数据。界面将自动显示预设下拉框，名称/数字只读，隐藏增删按钮。渲染器只接收 `{ id, label, value }[]`，与来源解耦，因此无需更改动画。

开发调试也可以使用 `window.ReplicaApp.setOptionSource({mode:'preset',presetId:'ez-zero'})`；再切回 `{mode:'custom'}` 会恢复当前会话中的自定义内容。批量修改先完整校验再提交，错误不会部分覆盖状态。该切换属于产品输入模式，不是安全权限控制。

`window.ReplicaApp` 同时提供 `getState`、`setOptions`、`setDesign`、`setView`、`seek`、`play`、`pause`。支持 WebMCP 的浏览器还可读取场景、批量修改选项与画面参数、定位时间和切换内容来源。

## 文件

- `dist/config.js`：选项规则与预设。
- `dist/default-settings.js`：用户提供的默认配置及参数存储版本。
- `dist/design.js`：统一画面参数、网页控件定义和参数校验。
- `dist/engine.js`：时间函数、布局和 Canvas 绘制；字形/光晕缓存、确定性故障、方向模糊。
- `dist/studio.js`：编辑、播放、音频同步和交互。
- `dist/frame-export.js`：按时间独立渲染 PNG 帧并打包 ZIP。
- `dist/styles.css`：适应桌面与移动设备的界面。
- `dist/assets/OFL.txt`：Saira 字体许可证。

使用 `node tests/scene.test.mjs` 运行数据校验、布局边界和时间连续性检查（也可用 `npm test`）。静态目录可以被普通静态服务器托管；当前为本地开发预览。

## 声效与噪声校准

波形输出位于工作区 analysis/audio-waveform.png，逐帧 RMS、峰值与高频能量比例位于 analysis/audio-waveform.json。对比 ref2：6.70–6.87 秒和 6.97–7.17 秒为两组明显短促声效，第一组声音比可见噪声早约一帧；7.30–7.77 秒有较弱高频干扰。图像噪声按视频帧间歇出现：202–205、210–214、221–222、224–228、232 帧（30 fps）。纹理以块状杂点和横条为主，7.47–7.60 秒叠加轻微撕裂和色边。它们在约 8.03 秒开始滚动前结束，静止数字卷轴位置不受影响。

波形用于核对声效的起止与能量，不能单独证明声音对应某种图像特效；图像干扰的类型和时点仍按 ref2 可见帧重建。

“从左到右就位错开”可调范围为 0–0.5 秒，代表相邻两位数字完成就位的时间差。较大值会延后右侧列的末尾就位，不再被末尾微调时长截断；前面的数字入场轨迹保持不变。
